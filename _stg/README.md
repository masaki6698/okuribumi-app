# `_stg/` — 検証環境向けのページ

**本番の利用者向けではない。** 検証環境（シドニー `travajxhsnbbkhwmotqp`）の Edge を
叩くように書き換えたコピーを置く場所。

## なぜ要るか

Edge 側の CORS は `https://okuribumi.app` の**完全一致のみ**を許可している
（`lastmail` リポの4関数）。したがって**検証用のページも同じドメインに置く必要がある**。
別サブドメイン（`stg.okuribumi.app` 等）に置くと CORS で弾かれる。

## 注意

- **`noindex` を必ず維持すること。**
- 本番のページを直接書き換えて検証しないこと（戻し忘れが事故になる）。
- 検証が済んだら、ここは残しておいてよい（本番の導線からはリンクしない）。
